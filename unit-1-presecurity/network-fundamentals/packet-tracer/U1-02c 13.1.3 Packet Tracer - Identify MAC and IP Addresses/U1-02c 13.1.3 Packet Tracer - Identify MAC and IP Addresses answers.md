#### Question Answer

**Question:** In the PDU information window, click the tab for the outbound PDU. How does the addressing differ, and why? Record the addressing in your table.

**Answer:** 
The source and destination addresses (for both MAC and IP) are swapped on the outbound ICMP Echo Reply PDU sent from the destination host (`172.16.31.2`) back to the originating host (`172.16.31.3`). 

* **Source MAC / IP:** Changes from `0060.7036.2849` / `172.16.31.3` to `000C:85CC:1DA7` / `172.16.31.2`.
* **Destination MAC / IP:** Changes from `000C:85CC:1DA7` / `172.16.31.2` to `0060.7036.2849` / `172.16.31.3`.

**Why:** When `172.16.31.2` receives the ICMP Echo Request, it generates an ICMP Echo Reply. To route the reply back to the original sender, `172.16.31.2` must set itself as the source device and set `172.16.31.3` as the target destination device.

### Part 3: Reflection Questions

**1. What different types of cables/media were used to connect devices?**
- Straight-through copper cables and wireless radio signals.

**2. Did the cables change the handling of the PDU in any way?**
- No, cables just move bits across the wire without touching packet data.

**3. Did the wireless Access Point do anything to the PDUs that it received?**
- Yes, it converted the frame format between Wi-Fi (802.11) and wired Ethernet (802.3).

**4. Was PDU addressing changed by the access point?**
- No, MAC and IP addresses stayed the exact same.

**5. What was the highest OSI layer that the Access Point used?**
- Layer 2 (Data Link).

**6. At what Layer of the OSI model do cables and access points operate?**
- Cables run at Layer 1; access points run at Layers 1 and 2.

**7. When examining the PDU Details tab, which MAC address appeared first, the source or the destination?**
- The destination MAC comes first.

**8. Sometimes PDUs were marked with red Xs while others had green check marks. What is the significance of these markings?**
- Green checks mean the frame was accepted; red Xs mean it was dropped or ignored by that port.

**9. Every time that the PDU was sent between the 10 network and the 172 network, there was a point where the MAC addresses suddenly changed. Where did that occur?**
- At the router.

**10. Which device uses MAC addresses that start with 00D0:BA?**
- The router interface on the 172.16.31.0 network.

**11. What devices did the other MAC addresses belong to?**
* `0060.7036.2849`: PC 172.16.31.3
* `000C.85CC.1DA7`: PC 172.16.31.2
* `00D0.D311.C788`: Router interface on the 10.10.10.0 network
* `0060.2F84.4AB6`: Wireless host 10.10.10.2

**12. Did the sending and receiving IPv4 addresses change in any of the PDUs?**
- No, end-to-end IP addresses don't change during transit.

**13. When you follow the reply to a ping, sometimes called a pong, what happens to the source and destination addresses?**
- They flip—the receiver becomes the source, and the original sender becomes the destination.

**14. Why do you think the interfaces of the router are part of two different IP networks?**
- Because a router's job is to pass traffic between separate networks, so each port has to sit on the network it connects to.

**15. Which IP networks are connected by the router?**
- The 172.16.31.0/24 network and the 10.10.10.0/24 network.
